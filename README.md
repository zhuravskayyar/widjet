# Stone Clock

Android-застосунок: кам’яний годинник, погодні віджети й живі шпалери для екрана блокування.

Погода надходить з Open-Meteo. Початкове місто — Мангейм; його можна змінити в застосунку.
Погодний блок містить тільки персонажа й температуру. У живих шпалерах і прев’ю очі швидко переводять
погляд, краплі падають, блискавки спалахують по черзі, крижані частинки кружляють, а вітер переносить
декоративні деталі. Обличчя, рот і температура залишаються нерухомими. Оригінальні PNG збережені.
Анімація зупиняється, коли шпалери приховані або екран вимкнений.
Звичайний віджет головного екрана показує статичний малюнок і актуальну температуру.
У розділі погоди кнопка **Переглянути анімації** дозволяє переглянути всі стани, не змінюючи справжню погоду.
Погода також перевіряється щохвилини, поки шпалери видно; запит надсилається лише коли кеш старший за 20 хвилин.

## Оновлення на телефоні без USB

1. Відкрий **Stone Clock → Оновлення застосунку → Перевірити оновлення**.
2. Натисни **Завантажити оновлення**, потім **Встановити оновлення**.
3. Першого разу дозволь встановлення для Stone Clock у системному вікні Android.
4. Підтвердь встановлення. Налаштування, фон і вибране місто зберігаються.

Застосунок також перевіряє нові версії під час відкриття, не частіше разу на годину.
Завантаження починається тільки після натискання користувачем кнопки.
APK перевіряється за SHA-256, назвою пакета, версією та сертифікатом підпису.

Перше встановлення або перевстановлення: [останній APK](https://github.com/zhuravskayyar/widjet/releases/latest/download/stone-clock.apk).

## Код → GitHub → APK

Кожен push у `main` запускає `.github/workflows/android.yml`:

1. GitHub збирає підписаний release APK і перевіряє Android lint.
2. Версія автоматично отримує більший `versionCode`.
3. Публікуються GitHub Release, `stone-clock.apk` і `update.json`.
4. Телефон знаходить нову версію через публічний HTTPS-файл `update.json`.

Для публікації локальних змін у PowerShell:

```powershell
.\scripts\publish.ps1 -Message "Опис змін"
```

Скрипт створює коміт, підтягує нові коміти з GitHub і надсилає зміни в `main`.
Якщо є конфлікт, він зупиняється для його вирішення. Force push не використовується.

Новий checkout:

```powershell
git clone https://github.com/zhuravskayyar/widjet.git
```

## Локальна збірка

Потрібні JDK 17+ та Android SDK 35. В Android Studio відкрий корінь проєкту.

```powershell
.\gradlew.bat :app:assembleDebug
```

Release-версія використовує той самий ключ підпису, що й початкова встановлена програма.
У GitHub Actions він зберігається в зашифрованому секреті `STONE_CLOCK_KEYSTORE_B64`.
Файли ключів, локальні налаштування SDK та результати збірки виключені через `.gitignore`.
Збережи локальний ключ `~/.android/debug.keystore`: він потрібен для сумісних локальних оновлень.

Джерела погоди: [Open-Meteo](https://open-meteo.com/), назви міст: GeoNames.
